# QEC-ADA offline research desk

Open `index.html` directly in a modern browser, or run
`uv run --no-project python scripts/qecada.py gui`.

No server, network, Node, framework, CDN, telemetry or account is needed.
The library is generated as a static, locally embedded catalogue so it works
under `file://`, including when browsers restrict local `fetch`.

The catalogue contains 103 file entries from the pinned QEC
snapshot. Click a link to open an unchanged local reference document.
The GF(3) workbench is educational JavaScript only; it is not Ada execution,
SPARK verification, or a general quantum error-correction decoder.

The native CLI and documentation verification remain independently available
without any graphical display. Source information: `docs/REFERENCE.md`.
